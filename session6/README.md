# Занятие 6: Python управляет базой, графики matplotlib

Урок 9 по шагам, один файл на шаг. Python подключается к PostgreSQL, создаёт базу и таблицу, записывает продажи и спрашивает у базы итоги (`GROUP BY` и `SUM`). Потом по этим итогам рисует три графика. После урока два запаса: домашка урока 9 и срез по базам данных (урок 10).

На слайдах база `test2` и пароль `1111`: это настройки автора урока. У нас база `postgres` и пароль `postgres`, как на компьютерах в классе. Остальные отличия от слайдов записаны в начале каждого файла.

## 1. Что нужно до первого запуска

**База.** Создавать ничего не нужно. Шаги 1 и 2 подключаются к базе `postgres`: она есть на любом PostgreSQL сразу после установки. Базу `sales_data` для урока создаёт шаг 2. Нужно только, чтобы PostgreSQL был установлен и запущен, а пароль пользователя `postgres` был `postgres`, как в классе. Как поставить PostgreSQL дома, написано в [конспекте занятия 5](https://timkiberone8-eng.github.io/python-kiber/zanyatie5/konspekt.html), раздел «1. Вход».

**Библиотеки psycopg2 и matplotlib.** Один раз, в терминале VS Code:

```bash
python -m pip install psycopg2-binary matplotlib
```

psycopg2 связывает Python с PostgreSQL, matplotlib рисует графики. Пакет называется `psycopg2-binary`, а в коде пишут `import psycopg2`: это тот же psycopg2, только собранный заранее, поэтому ставится без лишних программ.

Пиши `python -m pip`, а не просто `pip`. PATH это список папок, в которых терминал ищет программы. Если папки Scripts, где лежит `pip`, в этом списке нет, на `pip` терминал ответит, что команда не найдена, а `python -m pip` сработает: так pip запускает сам Python.

Проверь, что встало:

```bash
python -c "import psycopg2, matplotlib; print(psycopg2.__version__, matplotlib.__version__)"
```

Ответ: номера версий, например `2.9.13 (dt dec pq3 ext lo64) 3.11.2`. Если вместо них `ModuleNotFoundError`, загляни в раздел «Если что-то пошло не так».

## 2. Как запускать

В терминале VS Code перейди в папку занятия и запускай файлы по номерам:

Запускай в терминале, а не кнопкой Code Runner: в его панели Output вместо русских букв появляются ромбики с вопросительным знаком.

### Зачем autocommit и commit

Транзакция это пачка команд, которая сохраняется в базе целиком или не сохраняется вовсе. psycopg2 сам начинает транзакцию перед первой командой, а сохраняет её только `connection.commit()`. Поэтому в конце шагов 3 и 4 стоит `commit`: без него программа напечатает `Таблица создана`, а таблицы в базе не окажется.

Создавать и удалять базу внутри транзакции PostgreSQL не разрешает. Без `autocommit` шаг 2 падает так:

```
psycopg2.errors.ActiveSqlTransaction: ОШИБКА:  DROP DATABASE не может выполняться внутри блока транзакции
```

`connection.autocommit = True` значит: каждая команда сохраняется сразу, без транзакции. Поэтому в шагах 1 и 2 эта строка есть.

## 5. Если что-то пошло не так

| Что видишь | В чём дело | Что сделать |
|---|---|---|
| `ModuleNotFoundError: No module named 'psycopg2'` или `'matplotlib'` | библиотека не установлена | команда установки из раздела 1 |
| `UnicodeDecodeError: 'utf-8' codec can't decode byte 0xc2` | база не пустила: неверный пароль или нет такой базы. Отказ приходит по-русски, и psycopg2 не может его прочитать, поэтому ошибка такая странная | проверь пароль `postgres` в файле. Падает шаг 1 или 2: почти наверняка пароль, база `postgres` есть всегда. Падает шаг 3 и дальше: нет базы `sales_data`, запусти шаги 2, 3, 4 |
| `Connection refused` | PostgreSQL на компьютере не запущен | дома проверь, что PostgreSQL установлен; на занятии покажи экран |
| `отношение "sales" не существует` | «Отношением» PostgreSQL называет таблицу. Таблицы `sales` нет: не было шага 3 или после шага 2 не запущены 3 и 4 | запусти 03, потом 04 |
| `база данных "sales_data" занята другими пользователями` | к `sales_data` подключён кто-то ещё, например открытый SQL Shell после `\c sales_data` | закрой SQL Shell и запусти шаг 2 снова |
| `SyntaxError: invalid syntax` в строке с `year:` или `query:` | набрал со слайда серые подсказки PyCharm. Это не код | убери `year:`, `month:`, `day:`, `query:` |
| выручка вдвое больше: `7500` стало `15000` | продажи записаны два раза: шаг 4 без `DELETE FROM sales` запущен дважды | верни `DELETE FROM sales` и запусти шаг 4 |
| `TypeError: ufunc 'isfinite' not supported` у круговой диаграммы | деньги база отдаёт числом `Decimal`, а `plt.pie` его не берёт | `float(...)`, как в `extra1_pie_share.py` |
| вместо русских букв ромбики с вопросительным знаком | файл запущен кнопкой Code Runner или в отдельном окне Git Bash | запусти в терминале VS Code. В отдельном окне Git Bash: `python -X utf8 01_connect.py` |

Если ничего не помогло, сфотографируй экран с ошибкой и покажи на занятии.

## 6. Если psycopg2 не ставится

Есть другая библиотека для PostgreSQL, pg8000. Она написана на чистом Python, поэтому ставится там, где psycopg2 не встаёт:

```bash
python -m pip install pg8000 matplotlib
```

В файле поменяй две вещи:

- `import psycopg2` на `import pg8000.dbapi as psycopg2`;
- `dbname=` на `database=` (в шагах 1 и 2 и в файлах `extra2_*`).

Всё остальное работает как есть, вывод у всех файлов тот же.
