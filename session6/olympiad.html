1. Монетки

На столе лежат восемь монет одним рядком:

○○○○○○○○
12345678

За один ход можно взять одну монету, перенести её через две соседние монеты (монеты, а не стопки!) и положить на третью. За четыре хода нужно получить четыре стопки по две монеты в каждой. Как?

Решать на интерактивной странице →

Там монеты можно двигать мышкой, а неправильный ход страница не пропустит.

Не сходится?
  • Перепрыгнул стопку как одну монету? Так нельзя: в условии сказано «монеты, а не стопки».
  • Кажется, что решения нет, потому что мешает пустое место? Пустое место не монета, через него прыгать можно.
  • Получилась стопка из трёх монет? После этого четыре стопки по две уже не собрать: вернись к этому ходу.
  • Застрял на третьем или четвёртом ходу? Ошибка, скорее всего, в самом первом ходе: попробуй начать по-другому.

2. Районы, кварталы

План города представляет собой прямоугольник размером n × m километров, разбитых на кварталы: квадраты со стороной 1 километр. Между кварталами, а также по границе города проложены дороги. Например, если n = 2, m = 3, то план дорог следующий:

+---+---+---+
|   |   |   |
+---+---+---+
|   |   |   |
+---+---+---+

Определи суммарную длину всех дорог в городе в километрах. Единицу измерения указывать не нужно.

Ответом к этой задаче является некоторое выражение, которое может содержать целые числа, переменные n и m, операции сложения (обозначается +), вычитания (обозначается -), умножения (обозначается *) и круглые скобки для изменения порядка действий. Запись вида 2n для обозначения произведения числа 2 и переменной n неверная, нужно писать 2 * n.

Пример правильного (по форме записи) выражения: n + (m - 1) * 2

На плане n = 2 это два ряда кварталов сверху вниз, m = 3 это три квартала в ряду. Каждая сторона квадрата на плане это дорога длиной 1 километр.

Страница проверяет формулу на нескольких городах разной формы, а не только на плане из условия.

Не сходится?
  • Начни с самого маленького города, 1 × 1: один квартал, вокруг него 4 километра дороги. Твоя формула при n = 1 и m = 1 должна дать 4.
  • Совпало на одном городе ещё не значит, что формула верна: бывает, что формула случайно сходится на одном плане и ошибается на другом. Нарисуй 1 × 3, 2 × 2 и 3 × 4 и посчитай дороги по одному километру.
  • В ответе нельзя делить, есть только +, -, * и скобки.
Решил? Теперь на Python

Ответ в этой задаче записывается так же, как выражение в Python: те же +, -, * и скобки. Значит, формулу можно вставить в программу как есть.

Сначала один город, план из условия:

{% highlight python %} n = 2 m = 3 roads = ... # сюда твою формулу print(roads) {% endhighlight %}

Должно напечатать 17. А теперь программа посчитает сразу девять городов, от 1 × 1 до 3 × 3:

{% highlight python %} for n in range(1, 4): for m in range(1, 4): roads = ... # та же формула print(n, "x", m, ":", roads) {% endhighlight %}

Нарисуй два-три города из списка, посчитай дороги по одному километру и сверь с тем, что напечатала программа. Руками ты бы считал каждый город заново, а программе всё равно, сколько их.

4. Шаолиньский Даня

Даня готовится к спортивным соревнованиям. Он тренируется по системе шаолиньских монахов. Тренировка должна состоять из N подходов, каждый из которых длится M минут и S секунд, между каждой парой подряд идущих подходов должен быть перерыв длительностью P секунд.

Помоги Дане определить, сколько всего времени займёт тренировка.

Числа такие:

  • N (1 ≤ N ≤ 100): количество подходов;
  • M (0 ≤ M ≤ 59): количество минут в одном подходе;
  • S (0 ≤ S ≤ 59): количество секунд в одном подходе;
  • P (0 ≤ P ≤ 120): длительность паузы между подходами, выраженная в секундах.

Гарантируется, что один подход занимает ненулевое время.

Ответ: два целых числа, продолжительность тренировки в минутах и секундах. Первое число должно быть равно количеству полных минут в тренировке. Второе число должно быть равно количеству секунд в тренировке, находящемуся в диапазоне от 0 до 59 включительно.

Пример:

NMSPОтвет
43247017 минут 6 секунд

Это тоже задача на программу, и её тоже можно решать без программы: найди, как посчитать ответ для любых N, M, S и P.

Не сходится?
  • Сначала проверь своё правило на примере из таблицы: должно выйти 17 минут 6 секунд.
  • Вышло 18 минут 16 секунд? Посчитай, сколько перерывов между четырьмя подходами.
  • Вышло дробное число минут, например 17,1? Десятые доли минуты это не секунды. Переведи всё в секунды и только потом раздели на минуты и секунды.
Решил? Теперь на Python

В Python есть деление нацело // и остаток %. Например, 125 секунд это 125 // 60 = 2 минуты и 125 % 60 = 5 секунд. Впиши, как посчитать всё время тренировки в секундах:

{% highlight python %} N = 4 M = 3 S = 24 P = 70 total = ... # всё время тренировки в секундах print(total // 60, total % 60) {% endhighlight %}

Должно напечатать 17 6. Потом подставь числа из проверки выше.

Дополнительная задача: Лягушки и кузнечики

В крайних клетках полоски шириной в одну клетку и длиной в N клеток сидят лягушка и кузнечик: лягушка в клетке № 1, кузнечик в клетке № N. Каждую секунду лягушка прыгает в сторону кузнечика, и одновременно кузнечик прыгает в сторону лягушки. Лягушка может прыгать только на две или на три клетки, кузнечик: только на одну или на две клетки. За какое наименьшее время они смогут оказаться в одной клетке?

Длина полоски: 2 ≤ N ≤ 2 · 10⁹.

Ответ: минимальное количество секунд, через которое они встретятся. Если они не смогут оказаться в одной клетке, ответ -1.

Примеры:

NОтвет
51
92
Не сходится?
  • Нарисуй полоски из 2, 3 и 4 клеток и пройди прыжки на бумаге.
  • Лягушка и кузнечик не обязаны каждый раз прыгать на самое большое расстояние.
  • Подумай, всегда ли они вообще могут встретиться. Для этого случая в условии есть ответ -1.
  • N бывает до двух миллиардов: прыжки руками не пройти, нужно правило.
