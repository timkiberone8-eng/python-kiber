ШАГ 10. ДОБАВЛЯЕМ ТОВАР ЧЕРЕЗ БРАУЗЕР

ГДЕ: терминал рядом с manage.py.

python manage.py createsuperuser         # Создать администратора Django

Введи имя, почту (можно пустую) и пароль для входа в Django admin.
Символы пароля не отображаются; это НЕ пароль роли PostgreSQL.
Если Django не принимает слишком простой пароль — выбери более длинный.

python manage.py runserver               # Запустить сайт

В браузере: http://127.0.0.1:8000/admin/
Войди → Products → Add → name: Тетрадь, price: 50.00 → Save.
Открой товар, измени цену на 55.00, сохрани и обнови страницу.
Останови сервер Ctrl+C, снова запусти runserver, проверь, что товар остался.

ОБЯЗАТЕЛЬНЫЙ РЕЗУЛЬТАТ ГОТОВ: товар сохранён в PostgreSQL и виден в админке.
На главной пока надпись «Каталог работает». Список товаров там сам не появится:
для этого нужен шаблон, он находится в optional и не обязателен сегодня.
