# Занятие 8: путь одной продажи (закрепление уроков 9–10)

Сегодня не пишем новый проект, а проходим путь данных целиком: список в Python → `INSERT` → строка в таблице → `SELECT` с `GROUP BY` → ответ `fetchall` → график. Для общей практики нужна маленькая учебная таблица магазина. Её создают файлы этой папки.

| Файл | Что делает |
|---|---|
| `setup_session8.py` | создаёт таблицу `lesson8_receipts` и кладёт в неё шесть покупок; можно запускать сколько угодно раз, дублей не будет |
| `query_session8.py` | печатает все шесть строк таблицы |
| `daily_chart_session8.py` | рисует график выручки по дням; это задание на вторую половину урока, пока не запускай |

## Таблица магазина

| Дата (`sale_date`) | Товар (`product_name`) | Штук (`quantity`) | Цена одной штуки, руб. (`price`) |
|---|---|---:|---:|
| 20 октября | Сок | 2 | 100 |
| 20 октября | Вода | 1 | 20 |
| 21 октября | Сок | 1 | 100 |
| 21 октября | Сэндвич | 3 | 150 |
| 22 октября | Вода | 10 | 20 |
| 22 октября | Сок | 1 | 100 |

## Подготовка (один раз, лучше до начала урока)

1. Обнови учебник: в терминале VS Code, в папке учебника, `git pull`. Появится папка `session8`.
2. Открой свой рабочий файл, например шаг 4, и найди подключение: строку `database="..."` или `dbname="..."`. Это имя твоей базы.
3. В **каждом** из трёх файлов `session8` вверху впиши своё имя базы: `DB_NAME = "..."`. Сверь со своим рабочим файлом и пользователя с паролем: если они другие, поправь `DB_USER` и `DB_PASSWORD`.
4. Сохрани все три файла: «Файл → Сохранить всё». Затем в терминале перейди в папку `session8` (`cd session8`) и выполни:

```bash
python setup_session8.py
```

Должно напечататься:

```
Учебная таблица lesson8_receipts готова: 6 строк.
```

5. Затем:

```bash
python query_session8.py
```

Должны напечататься шесть строк, как в таблице магазина:

```
('Сок', 2, Decimal('100.00'), datetime.date(2026, 10, 20))
('Вода', 1, Decimal('20.00'), datetime.date(2026, 10, 20))
('Сок', 1, Decimal('100.00'), datetime.date(2026, 10, 21))
('Сэндвич', 3, Decimal('150.00'), datetime.date(2026, 10, 21))
('Вода', 10, Decimal('20.00'), datetime.date(2026, 10, 22))
('Сок', 1, Decimal('100.00'), datetime.date(2026, 10, 22))
```

`Decimal('100.00')` это просто число 100: так Python показывает точные деньги из базы. `datetime.date(2026, 10, 20)` это дата 20 октября. Ничего чинить не нужно.

## Если что-то не так

- **`ModuleNotFoundError`:** в терминале `python -m pip install psycopg2-binary` или `python -m pip install matplotlib`, смотря какое имя в сообщении.
- **Ошибка про пароль или базу:** сверь `DB_NAME`, `DB_USER` и `DB_PASSWORD` со своим рабочим файлом.
- **Изменения в файлах учебника мешают `git pull`:** не удаляй их сам, позови преподавателя.

Задания урока на экране у преподавателя и на листе занятия. Свои решения сохраняй в своей тетради, а не в учебнике.
