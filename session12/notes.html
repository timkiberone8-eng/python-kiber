3. Связываем форму и фильтр

Покажите цепочку. При отправке формы методом GET поле с name="max_price" добавит к адресу ?max_price=100. В home Django прочитает строку '100', преобразует её в число и выберет товары с price__lte=100, то есть с ценой не выше 100 ₽. Шаблон получит список products и отрисует карточки.

  1. В шаблоне над карточками найдите форму. Если её нет, возьмите фрагмент ниже. Если форма уже находится внутри блока {% raw %}{% if show_budget %}{% endraw %}, сохраните этот блок.
  2. В views.py проверьте импорты render и Product. Замените только home, сохранив имя шаблона из своего рабочего проекта. Старый фиксированный порог заменяем условием, которое использует введённое число.
  3. Откройте /?max_price=60 вручную. Затем введите 60 в поле и нажмите «Показать». Сравните адрес и выдачу. На четырёх демонстрационных товарах должна остаться ручка.
Фрагмент формы для шаблона {% raw %} 
<form class="budget-form" method="get">
    <label for="max-price">Бюджет до, ₽</label>
    <input id="max-price" name="max_price" type="number"
           min="0" max="999999" step="1" value="{{ max_price }}">
    <button type="submit">Показать</button>
    <a href="/">Сбросить</a>
</form>
{% endraw %}

Ссылка «Сбросить» открывает главную без параметров. Атрибут value подставляет сумму из Django, чтобы после обновления было видно, какой порог применён.

Представление home · шаг 3 
from django.shortcuts import render
from .models import Product


def home(request):
    max_price = request.GET.get('max_price', '')
    products = Product.objects.order_by('price', 'id')

    if max_price:
        budget = int(max_price)
        products = products.filter(price__lte=budget)

    return render(request, 'catalog/product_list.html', {
        'products': products,
        'show_budget': True,
        'max_price': max_price,
    })

Пустая строка пропускает if, поэтому остаётся полный отсортированный список. Флаг show_budget открывает условный блок формы в учебном шаблоне.

5. Проверяем выдачу и сброс

Перед отправкой формы попросите предсказать, какие карточки останутся. Сверьте адрес, поле и порядок. Для своих товаров используйте фактические цены.

  • 99 ₽ → ручка, тетрадь. Линейка за 100 ₽ пока не проходит.
  • 100 ₽ → ручка, тетрадь, линейка. price__lte включает границу. В поле остаётся 100.
  • Пустое поле → /?max_price=, все четыре карточки от дешёвых к дорогим.
  • «Сбросить» после 100 ₽ → чистый адрес /, пустое поле, рюкзак снова виден.
  • 0 ₽ → параметр max_price=0 включает фильтр. На этих товарах выдача пуста.
По темпу · защита от некорректного ввода

Если основные проверки уже проходят, откройте на локальном сервере /?max_price=abc. Форма принимает числа, но адрес можно набрать вручную. На шаге 3 вызов int('abc') вызывает ValueError.

В шаге 4 перед int() проверяется, что строка состоит из десятичных цифр и содержит не больше шести знаков. Примените этот шаг, сохранив путь к своему шаблону. В учебном шаблоне найдите блок error под формой и добавьте его, если на ПК используется другая версия.

Повторите /?max_price=abc: ожидаются подсказка и полный список. Затем отправьте 100 ₽ через форму и убедитесь, что подсказка исчезла и фильтр снова работает.
