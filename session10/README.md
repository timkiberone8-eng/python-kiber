# Занятие 10. Первый экран каталога

Продолжаем свой проект Django с папкой `catalog`. Если модели товара и админки ещё нет, откройте [шаги 7–10 занятия 9](../session9/README.md). Прежние страницы и маршруты проекта сохраните.

## 1. Проверяем, что товар сохраняется

1. Откройте в терминале папку с `manage.py`. Проверьте, какую базу сейчас читает Django:

   ```powershell
   python manage.py shell -c "from django.db import connection; print(connection.vendor)"
   ```

   `postgresql` означает подключение к серверу PostgreSQL. `sqlite` означает работу с файловой базой SQLite. При смене базы Django видит другой набор таблиц, товаров и пользователей админки. Для проверки пользуйтесь той базой, которую уже настроили в своём проекте.

2. Выполните `python manage.py runserver` и откройте [админку](http://127.0.0.1:8000/admin/). Добавьте товар «Тетрадь» за 80 ₽ или выберите уже добавленный товар. Поменяйте цену, например на 90 ₽, и сохраните.
3. Остановите сервер через Ctrl+C, снова выполните `python manage.py runserver` и проверьте цену в админке. Если цена осталась новой, изменение сохранилось в базе.

Если Django сообщает, что таблицы нет, сначала выполните `python manage.py showmigrations catalog`. У миграций, применённых к текущей базе, стоит `[X]`. Для настройки таблицы и входа вернитесь к [шагам 7–10 занятия 9](../session9/README.md).

## 2. Показываем товары на главной

Откройте `catalog/views.py` рядом с `manage.py`. По [образцу](02_catalog_home.py) добавьте импорт `Product` и замените только функцию `home`. Импорт `HttpResponse` оставьте один раз. Остальные функции оставьте в файле.

Откройте [главную страницу](http://127.0.0.1:8000/). `Product.objects.all()` получает товары из базы, цикл собирает из них строки с названиями и ценами, а `HttpResponse` отправляет обычный текст браузеру. Если товаров нет, страница показывает сообщение об этом.

Проверьте себя. Добавьте второй товар, обновите главную и найдите обе строки. Затем измените цену одного товара в админке и обновите главную снова. Должна появиться новая цена. Этот шаг меняет отображение, поэтому новой миграции для него не требуется.
